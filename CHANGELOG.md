## [0.1.0] — 2026-10-12

First development release.

### Added
- Block theme foundation: `theme.json` v3 design tokens (11 colours, 7 fluid sizes, 8 spacing steps, radius/motion custom properties), self-hosted Cormorant Garamond and DM Sans (OFL).
- Templates: index, home (journal), front page, page, landing page (no title), single, archive, search, 404, WooCommerce product catalog, product search results, single product.
- Template parts: header (logo/title, navigation, search, account, mini cart), footer, post meta, comments.
- 33 patterns: storefront sections, storytelling sections, inspiration board, gift finder page, about/contact/FAQ/shipping/returns/legal pages, header with announcement bar.
- Style variations: Blush Atelier, Sage & Oat, Lavender Studio.
- Block styles: Eyebrow, Italic accent, Card, Arch, Checklist, Underline navigation.
- 12 original CC0 illustrations and a generator script.
- Demo store seed (`demo/seed.php`) and WordPress Playground blueprints.
- Test scripts: static validation, contrast, runtime smoke test, responsive overflow, screenshots.
- Documentation: requirements, market analysis, architecture, design system, test plan, store-owner guide, release guide, decision log, roadmap.
